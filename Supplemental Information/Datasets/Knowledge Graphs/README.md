## Knowledge Graph Versions

- **[Knowledge Graph V1.0](https://drive.google.com/drive/folders/1XRkLqilkXGiqzQHBkKjW_ycAyHEYCweJ?usp=sharing)**: The version used in our manuscript, constructed from scientific literature available up to **December 1, 2025**.
- **[Knowledge Graph V1.1](https://drive.google.com/drive/folders/1yrQDH95swqbOzdNxPVLduCl_2vJp3CIq?usp=sharing)**: An updated version that extends V1.0 by incorporating additional scientific literature published between **December 1, 2025, and September 1, 2026**.
