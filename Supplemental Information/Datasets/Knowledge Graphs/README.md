## Knowledge Graph Versions

We provide two versions of the DeepBreeding Knowledge Graph:

- **Knowledge Graph V1.0**: The version used in our manuscript, constructed from scientific literature available up to **December 1, 2025**.
- **Knowledge Graph V1.1**: An updated version that extends V1.0 by incorporating additional scientific literature published between **December 1, 2025, and September 1, 2026**.

**Note:** V1.0 is provided to support the reproducibility of the results reported in the manuscript, while V1.1 offers an expanded and more up-to-date knowledge resource.
